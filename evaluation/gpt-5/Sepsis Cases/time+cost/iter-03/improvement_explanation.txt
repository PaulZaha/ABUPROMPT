Key improvements to reduce execution time and cost while keeping feasibility in an ER sepsis context:
- Parallelize labs and IV fluids directly after ER Triage: Instead of waiting for ER Sepsis Triage to complete, leucocytes, CRP, optional lactate, and optional IV fluids are triggered in parallel right after ER Triage via standing orders. This removes idle time and shortens the critical path, reducing overall throughput time.
- Start antibiotics as soon as ER Sepsis Triage completes (do not wait for labs or fluids): Eliminating the prior dependency on labs for starting antibiotics aligns with clinical best practice (do not delay antibiotics for labs) and significantly reduces door-to-antibiotic time.
- Keep cost control with fine-grained optionality: Make each cost-driving task optional individually (lactate, IV fluids, antibiotics). This prevents unnecessary execution when sepsis suspicion is low or clinical criteria do not warrant them, directly reducing execution cost while preserving the ability to act fast when needed.
- Flatten nested partial orders: Replace the nested partial orders with a single top-level partial order and use XOR for optional elements. This reduces modeling complexity and avoids hidden sequential constraints, ensuring true concurrency where intended, which in practice streamlines coordination and reduces wait times.
Together, these changes shorten the longest path by overlapping work and removing unnecessary waits, while optional elements let the team skip nonessential steps, yielding lower cycle time and cost.
