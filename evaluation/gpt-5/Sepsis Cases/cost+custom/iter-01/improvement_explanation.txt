Key design issues in the original model: (1) After ER Sepsis Triage the entire diagnostic/treatment block could be skipped, which risks under-treatment of true sepsis; (2) IV Liquids were enforced before IV Antibiotics, potentially delaying antibiotics; (3) Lactic acid testing was available to everyone instead of being targeted to suspected sepsis, increasing cost and noise; (4) No explicit separation of sepsis vs non-sepsis flows, which can lead to antibiotic overuse (wrong treatments) and unnecessary tests. Improvements made: - Introduced an explicit xor branch after ER Sepsis Triage: Sepsis Path vs Non-Sepsis Path. This focuses antibiotics and lactate testing on the right patients and reduces unnecessary cost and wrong treatments. - Sepsis Path: mandatory concurrent diagnostics (Leucocytes, CRP, LacticAcid) with LacticAcid modeled as a self-loop (repeat from 1..n) for clinically indicated re-measurement; treatment (IV Liquid and IV Antibiotics) can start as soon as diagnostics are completed and can run concurrently to avoid delaying antibiotics. Edges enforce diagnostics before treatment, reducing wrong treatments and ensuring tests guide therapy. - Non-Sepsis Path: no antibiotics; minimal diagnostics (Leucocytes, CRP) and IV Liquid are optional and concurrent, and LacticAcid is omitted, cutting execution cost while avoiding antibiotic misuse. - Removed the global option to skip the entire post-triage block for sepsis-suspected cases; the sepsis branch makes labs and treatment mandatory once that branch is taken, reducing under-treatment. - Flattened dependencies in the sepsis path into a single partial order so the sequence constraints are explicit and there is no partial order nested within another partial order, improving model correctness. These changes reduce cost by eliminating unnecessary lactate tests and antibiotics for non-sepsis, and decrease wrong treatments by gating antibiotics behind sepsis suspicion and diagnostics, while also avoiding treatment omission in confirmed/suspected sepsis.
