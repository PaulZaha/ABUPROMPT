Key issues in the as-is model that drive cost and harm external quality: (1) critical checks and outcomes are optional (CODE OK, RELEASE, BILLED), which allows cases to be finalized or left unresolved without quality assurance; (2) FIN can run concurrently with coding/release, enabling premature finalization; (3) a silent skip after NEW creates unresolved cases; (4) CHANGE DIAGN is not tied to a validation loop, causing late rework. Improvements implemented: (a) explicit early decision after NEW: XOR between DELETE (clean cancellation) and the processing path; we remove the skip path to ensure every case has a clear outcome—this improves external quality and avoids follow-up costs; (b) enforce a clean sequence for the processing path: RELEASE → quality gate → FIN → BILLED; this removes risky concurrency and ensures only validated work proceeds; (c) introduce a localized rework loop: loop(CODE OK, CHANGE DIAGN). CODE OK is executed; only if a discrepancy is found is CHANGE DIAGN performed, which forces a re-check (CODE OK) before proceeding. This contains rework within coding, preventing costly rework on FIN/BILLED and reducing chargebacks/complaints; (d) make BILLED mandatory on the processing path to eliminate revenue leakage and customer confusion; cases not intended for billing exit via DELETE. Net effect: reduced execution cost through earlier exit, elimination of rework downstream, and prevention of error propagation; improved external quality via mandatory validation and clear, consistent outcomes for customers.
