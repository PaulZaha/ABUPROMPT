As process owner, I simplified and gated the flow to cut execution cost by removing waste, sequencing to avoid rework, and eliminating unnecessary parallelism. Key changes: 1) Removed the top-level do-nothing option after NEW; cases must either be explicitly deleted or processed, preventing orphaned items that incur monitoring/cleanup cost. 2) Introduced an explicit billing decision immediately after the quality gate: after CODE OK, we XOR into either a billing path or a no-bill path. This ensures RELEASE only happens for billable cases, avoiding unnecessary RELEASE work when not billing. 3) Enforced first-time-right sequencing to reduce rework: CHANGE DIAGN (optional) happens before CODE OK; CODE OK before any billing decision; on the billing path, RELEASE precedes FIN, and BILLED occurs after FIN within that branch. This removes the prior concurrency between FIN and RELEASE/CODE OK that often causes rework and coordination overhead. 4) Consolidated optionality: rather than making quality/billing steps optional everywhere, we make CODE OK a mandatory quality gate for processed cases to avoid downstream denial/rework costs, and keep CHANGE DIAGN optional but early. Together, these changes reduce wasted activity (no unnecessary RELEASE in no-bill cases), cut rework/adjustments, and eliminate parallel coordination overhead, lowering execution cost per case.
